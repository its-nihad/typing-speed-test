# RapidType

RapidType is a typing speed test built as a single HTML file, with no libraries and no build step. Its look is modeled on a chronograph: a ticked dial with a brass arc counts down your time while your live words per minute sit at its center, on a steel and graphite palette that switches to a light titanium variant to match your system theme.

Click this link to view the project: https://its-nihad.github.io/typing-speed-test/

Pick a 15, 30 or 60 second test, click the text and start typing. When time runs out you get your words per minute, accuracy, raw speed, characters typed and error count, and your best score for each test length is saved in your browser's local storage. Press Tab or Esc at any point to restart with a fresh set of words.

To run it yourself, open index.html in any modern browser. To host it, put the file in a GitHub repository and turn on GitHub Pages for the main branch. Speed is counted the standard way, with every five correct characters counting as one word, and accuracy is the share of keystrokes that matched the text.
